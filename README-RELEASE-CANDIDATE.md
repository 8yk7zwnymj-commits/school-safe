# SCHOOL SAFE — Release Candidate

รุ่นสำหรับแชร์ให้เพื่อนทดลองใช้งาน

## จุดเปลี่ยนหลัก
- ปรับ Desktop navigation เป็น sidebar แบบแพลตฟอร์ม และคงเมนู responsive สำหรับ tablet/mobile
- ยกระดับหน้าอุปกรณ์ความปลอดภัยด้วยภาพประกอบอุปกรณ์ 6 ประเภท
- เพิ่มตัวกรองหมวดและค้นหาอุปกรณ์แบบใช้งานจริง
- คงระบบ Assessment, Training, 4 games, Safety Route 15 ด่าน, Profile/Safety Passport และข้อมูลผู้ใช้เดิม
- เนื้อหาอุปกรณ์เน้นการรู้จัก/สังเกต/แจ้งผู้รับผิดชอบ ไม่ชวนทดลองอุปกรณ์ที่ต้องได้รับการฝึก

## ก่อนแชร์
เปิด `index.html` เพื่อทดลองแบบ local ได้ หรืออัปโหลดโฟลเดอร์ทั้งหมดขึ้น GitHub Pages
หมายเหตุ: ระบบบัญชียังเป็น localStorage ดังนั้นข้อมูลผู้ใช้จะอยู่ใน browser/device ที่สมัครเท่านั้น
